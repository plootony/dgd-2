# Weapon Sway

Godot 4 addon: camera-space weapon lag with independent per-weapon Resource profiles.
No dependency on DGD, Fusion, the input map, weapon damage or animation rigs.

## Настройка в DGD

Плагин уже включён: Project → Project Settings → Plugins → Weapon Sway.
В панели Weapon Sway выберите AK74U или Beretta; параметры появятся в инспекторе.
Сохраните ресурс (Ctrl+S) и перезапустите запущенную игру, чтобы применить изменения.
Профили находятся в `res://weapon_sway_profiles`. Кнопка «Создать профиль…» создаёт новый ресурс;
сохраняйте его в эту папку, чтобы он появился в списке. После переименования нажмите «Обновить список».
Создание профиля не создаёт оружие: назначьте ресурс полю `sway_profile` нужного WeaponDefinition.
Для независимых настроек используйте отдельный ресурс для каждого ствола.
Кнопка «Сбросить по умолчанию» возвращает общие стандартные параметры плагина
для выбранного профиля, сохраняя его имя. Это не восстановление исходного пресета AK/Beretta.
Сброс можно отменить Ctrl+Z; результат сохраняется Ctrl+S.

| Параметр | Значение |
| --- | --- |
| Enabled | Включение эффекта для выбранного оружия |
| Lag Seconds | Сила отставания от угловой скорости камеры |
| Response Speed | Скорость набора отклонения; больше — быстрее |
| Return Speed | Скорость возврата после остановки; меньше — дольше |
| Max Angle Degrees | Предел суммарного отклонения по двум осям |
| Position Gain / Max Offset | Сила и предел смещения в метрах |
| Roll Ratio | Боковой наклон от горизонтального поворота |
| Aim Multiplier | Остаточная сила инерции камеры при полном ADS |

## Пресеты массы и вязкости

В панели выберите профиль оружия, затем «Пресет инерции» и нажмите
«Применить пресет к оружию». Сохраните Ctrl+S и перезапустите игру.
Применение отменяется Ctrl+Z. Имя профиля, кривая Лиссажу и модификаторы стоек сохраняются.
Установка плагина сама по себе не заменяет пользовательские настройки оружия.

| № | Пресет | Характер |
| --- | --- | --- |
| 01 | Невесомое | Минимальный ход, очень быстрый возврат |
| 02 | Лёгкое | Небольшая мягкая задержка |
| 03 | Быстрый пистолет | Отзывчивое, с заметным остаточным ходом |
| 04 | Упругое | Более выраженное прохождение через нейтраль |
| 05 | Сбалансированное | Средний вес и затухание |
| 06 | Тяжёлый автомат | Медленнее разгоняется и тормозит |
| 07 | Вязкое | Сильнее гасит колебания, тягучий возврат |
| 08 | Тяжёлое и упругое | Большая инерция с заметным остаточным колебанием |
| 09 | Очень вязкое | Медленное возвращение почти без раскачивания |
| 10 | Максимальный вес | Самая медленная реакция и большой ход |

Все пресеты включают `Spring Enabled` и задают `Spring Mass`, `Spring Stiffness`,
`Spring Damping`, силу отставания, пределы отклонения, смещение и наклон.
Масса здесь — относительный параметр настройки, не килограммы оружия.
Больше массы замедляет разгон; больше жёсткости усиливает возврат;
больше демпфирования подавляет раскачивание и делает возврат более вязким.
Параметры `Response Speed` и `Return Speed` используются только при выключенном Spring Enabled.
Пресеты сохраняют 10% инерции в ADS; этот множитель можно отдельно изменить.
Модель хранит угловую скорость между кадрами и использует аналитическое решение пружины.

## Покачивание по Лиссажу

В инспекторе есть отдельные группы Camera inertia, Lissajous pattern и Pattern modifiers.
Инерция от мыши и периодическое покачивание настраиваются независимо.
`Pattern Enabled` выключает кривую; `Enabled` выключает оба эффекта.
`Base Amplitude Degrees` задаёт горизонтальную и вертикальную амплитуду в градусах.
`Base Frequency Hz`, `Frequency Ratio` и `Phase Degrees` задают частоту, отношение частот осей
и сдвиг фазы. По умолчанию 0.2 Гц, отношение 1:2 и 90°. Это наш начальный пресет, не точная
реконструкция параметров Insurgency.

Модификаторы взяты как референс из [патчноутов 1.5](https://steamdb.info/patchnotes/4468369/):
амплитуда ×0.5 в приседе, ×0.3 лёжа, ×1.15 в движении; скорость ×1.5 в движении;
фокус уменьшает обе величины до ×0.4. Множители перемножаются поверх базовых значений.
Историческое снижение скорости на 20% отдельно не накладывается: прежняя базовая частота
той игры неизвестна, у нас задаётся своя частота напрямую.

В DGD фокус удерживается **Shift + ПКМ**, движение определяется по фактической скорости,
присед — по состоянию персонажа. Положение лёжа поддержано API, но в контроллере игрока его пока нет.
`Pattern Aim Multiplier` управляет покачиванием в ADS (по умолчанию 1); для полного отсутствия
покачивания мушки выставьте его и `Aim Multiplier` в 0. Фокус не имеет ограничения по выносливости.
`Context Response` регулирует плавность изменения модификаторов; фаза при переходе не сбрасывается.

В другом проекте передавайте в `step(profile, look_delta, delta, ads_blend, stance, moving, focused)`
стойку из `SwayMotion.Stance` (STANDING/CROUCHED/PRONE), движение и фокус.
Существующая короткая форма вызова остаётся рабочей: по умолчанию персонаж стоит без фокуса.

Это только визуальное движение. Прицел, камера и направление рейкаста не изменяются.
Бег, стрельба и перезарядка продолжают использовать собственные анимации.
При смене оружия, смерти, переключении вида и открытии меню накопленная инерция сбрасывается.

## Подключение в другом проекте

Скопируйте папку `addons/weapon_sway`, включите плагин и создайте профили.
Папка профилей задаётся Project Setting `weapon_sway/profile_directory`.
Runtime работает и без включённой редакторской панели.

```gdscript
const SwayMotion = preload("res://addons/weapon_sway/sway_motion.gd")
const SwayProfile = preload("res://addons/weapon_sway/sway_profile.gd")
@export var profile: SwayProfile
var motion = SwayMotion.new()
var look_delta = Vector2.ZERO

# Accumulate actual camera pitch/yaw changes in radians, after sensitivity/clamping.
func camera_turned(pitch_delta: float, yaw_delta: float) -> void:
    look_delta += Vector2(pitch_delta, yaw_delta)

# Call once per rendered frame after calculating the base weapon pose.
func apply_sway(delta: float, ads_blend: float, base_pose: Transform3D) -> void:
    $Weapon.transform = motion.step(profile, look_delta, delta, ads_blend) * base_pose
    look_delta = Vector2.ZERO
```

Используйте базовую позу без эффекта предыдущего кадра, иначе смещение будет накапливаться.
Для Node3D-пивота непосредственно под камерой можно назначать результат `step` самому пивоту.
На экипировке, телепортации камеры и блокировке ввода вызывайте `motion.reset()` и обнуляйте
накопленный ввод. Каждый активный экземпляр оружия/игрока должен иметь собственный SwayMotion;
профиль хранит только параметры и может безопасно использоваться совместно.
